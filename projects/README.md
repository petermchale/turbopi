# Projects

Things we build with the robot. One directory per project.

Nothing here yet — this is where the kids' projects will go.

## Adding one

Make a directory with a short, specific name, and give it a `README.md` that
answers four questions:

1. **What does it do?** One or two sentences, written so someone who has never
   seen it understands.
2. **How do you run it?** The actual commands, in order.
3. **What does it need?** Python packages, sensors, anything that must be
   plugged in or switched on.
4. **What did we learn?** Including the things that did not work. This is
   usually the most valuable part and the first thing forgotten.

Keep anything machine-specific — addresses, passwords, paths — out of the
project and in `local-config.sh` at the repo root, which is gitignored.

See [`../robot-setup/README.md`](../robot-setup/README.md) for how to connect
to the robot in the first place.
